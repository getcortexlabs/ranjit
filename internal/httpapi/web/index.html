Configure suas credenciais com ranjit configure e reinicie o servidor. Conectores bancários são experimentais e exigem uma aplicação habilitada.

Uma cópia dos seus dados

O backup guarda o histórico desta instalação. Credenciais de bancos e a configuração ficam nos arquivos locais.

ranjit backup minha-copia.db

Para restaurar: pare o servidor e execute ranjit restore --replace minha-copia.db (opções antes do arquivo).
